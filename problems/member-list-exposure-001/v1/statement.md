# 전체 멤버 조회 후 저장 상태가 손상되는 버그

`MemoryMemberRepository.findAll()`로 전체 멤버를 조회한 호출자가 결과 목록을
정리하거나 일부 항목을 제거하면, 조회 결과뿐 아니라 저장소에 보관된 멤버까지
사라집니다. 조회 API가 저장소의 내부 컬렉션을 그대로 노출해서 외부 변경이 저장
상태로 전파되는 것이 원인입니다.

조회 결과를 호출자가 변경하더라도 저장소의 멤버와 파트별 인덱스는 영향을 받지
않아야 합니다. 저장, 이름 조회, 중복 검사와 파트별 조회의 기존 동작도 유지하세요.

수정 가능한 파일은 다음 하나뿐입니다.

```text
src/main/java/package2/MemoryMemberRepository.java
```

Java 21과 제공된 Gradle/JUnit 테스트를 사용해 동작을 수정하세요.
