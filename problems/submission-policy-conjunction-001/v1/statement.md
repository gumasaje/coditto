# 제출 정책 조건 결합 오류

멤버가 과제를 제출하려면 역할 정책과 최소 기수 정책을 모두 통과해야 합니다.
그런데 `Role.canSubmitByAll()`은 둘 중 하나만 통과해도 제출을 허용해, 기수가 낮은
아기사자나 제출 권한이 없는 운영진까지 허용합니다.

각 정책을 개별 조회하는 동작과 두 정책을 모두 통과한 아기사자의 제출은 보존하면서,
두 조건 중 하나라도 실패하면 최종 제출을 거부하도록 수정하세요.

수정 가능한 파일은 `Role.java` 하나뿐입니다.

Java 21과 JUnit 5 기반 공식 테스트로 동작을 검증합니다.
